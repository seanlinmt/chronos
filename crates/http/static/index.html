Thermal & Load

Left axis is GPU-module power draw in watts, 0–150 W. Right axis carries temperature in °C and load in %, both 0–100. Power is the GPU module only: GB10 exposes no power limit and no CPU/SoC power sensor. Average draw is the solid line, instantaneous draw the thin dimmed dashed one. CPU/SoC is the hottest ACPI thermal zone the node reports, not a per-core sensor; fan and RAM temperatures are not exposed, so they are not charted. Readouts turn amber or red above the thresholds — GPU 80/90 °C, CPU/SoC 90/95 °C, CPU load 85%; GPU load and both power lines stay neutral, since a node sitting at 100% while it serves is normal. History is held in this browser tab only — 2 s samples, 30 min max, lost on reload.
